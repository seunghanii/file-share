# 파일공유 (윈도우 PC ↔ 같은 Wi-Fi의 다른 기기)

## 사용법
1. `파일공유.exe`를 PC의 원하는 폴더(예: 바탕화면의 '파일공유' 폴더)에 넣고 더블클릭
   - 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
   - 방화벽 창이 뜨면 **개인 네트워크 허용**
2. 파일공유 프로그램 창이 열립니다.
3. 휴대폰·태블릿 카메라로 창의 **QR 코드**를 찍거나, 표시된 주소를 브라우저에 입력
   (다른 PC도 브라우저로 접속 가능. 같은 Wi-Fi여야 합니다)
   - 노트북을 들고 다른 곳으로 옮겨 IP가 바뀌어도, 창의 주소와 QR이 몇 초 안에 자동으로 바뀜 (다시 켤 필요 없음)

## PC 프로그램 창
- **＋ 파일 추가** 또는 창에 파일을 끌어다 놓기 → 다른 기기에서 바로 받을 수 있음
- **Ctrl+V 붙여넣기**: 캡처(Win+Shift+S) 이미지, 복사한 텍스트, 탐색기에서 복사한 파일을 창에서 Ctrl+V 하면 바로 추가됨
  - 텍스트는 파일(.txt)로 만들지 않고 목록에 텍스트 항목(보라색 T)으로 올라감
- 텍스트와 이미지 항목 오른쪽 **복사** 버튼을 누르면 바로 클립보드에 복사됨 → 원하는 곳에 Ctrl+V
  (항목을 선택하고 **Ctrl+C** 해도 같음)
- 창 오른쪽 위 **종료** 버튼으로 프로그램을 완전히 끌 수 있음
- 다른 기기에서 올린 파일은 목록에 자동으로 나타남
- 사진(JPG, PNG, GIF)은 목록에 미리보기(썸네일)로 보임
- 더블클릭 또는 **열기**: 기본 프로그램(엑셀, 파워포인트 등)으로 열기
- **폴더에서 보기**, **다른 이름으로 저장**, **삭제**(Delete 키도 가능)
- 파일과 텍스트는 exe 옆의 `공유폴더`에 저장됨

## 닫기와 종료
- 창의 **X(닫기)** 를 누르면 창만 숨고, 작업표시줄 오른쪽 아래 트레이(^ 안쪽)에서 계속 실행됩니다.
- 트레이의 파란 화살표 아이콘
  - 왼쪽 클릭: 창 다시 열기
  - 오른쪽 클릭: 접속 주소 확인, 저장 폴더 열기, **종료**
- exe를 다시 실행해도 새로 켜지지 않고 숨겨진 창이 다시 나타납니다.

## 다른 기기 (휴대폰·태블릿·PC 브라우저)
- 브라우저로 접속해서 올리기, 받기, 삭제
- **텍스트 보내기** 칸에 붙여넣고 보내면 PC 목록에 텍스트 항목으로 올라가고, PC에서 **복사** 한 번으로 복사됨
- 목록의 텍스트 **복사** 버튼: 누르면 바로 복사됨
- 목록의 이미지 **복사** 버튼: 이미지가 크게 열리면 길게 눌러 '복사'
  (브라우저가 http 주소에서 이미지를 바로 복사하는 것을 막기 때문에 한 단계가 더 필요합니다)
- 아이폰·아이패드에서 받은 파일은 파일 앱 → 다운로드 폴더에 저장됨
- 공유 버튼 → "홈 화면에 추가"로 앱처럼 사용

## 접속 PIN
- 다른 기기에서 처음 접속하면 4자리 PIN을 물어봅니다. PC 창의 접속 카드에 보이는 **접속 PIN**을 입력하면 그 기기는 다음부터 묻지 않습니다.
- **PIN 바꾸기**를 누르면 새 번호로 바뀌고, 이미 입력했던 기기도 모두 새 번호를 다시 입력해야 합니다.
- 5번 틀리면 1분 동안 입력할 수 없습니다. 이 PC에서 여는 화면은 PIN을 묻지 않습니다.

## 아이폰·아이패드에서 사진 바로 복사 (한 번만 설정)
- 브라우저는 보안 주소(https)에서만 사진 복사를 허용해서, http 주소에서는 사진 [복사]가 길게 누르기로만 됩니다.
- 접속 페이지 위쪽 안내의 **설정 방법**을 따라 이 PC 전용 인증서를 한 번 설치·신뢰하면, 다음부터는 자동으로 보안 주소(https://IP:8443)로 넘어가고 [복사]만 눌러도 사진이 복사됩니다.
- 인증서는 같은 네트워크 안의 사설 주소(10.x, 172.16~31.x, 192.168.x 등)에만 쓸 수 있도록 제한되어 있습니다.

## 팁
- PC 켤 때 자동 실행: `Win+R` → `shell:startup` → 열린 폴더에 exe **바로가기** 넣기
- 접속 PIN이 있어도 공용 Wi-Fi에서는 사용하지 않는 것이 좋습니다.

## 폴더 구성
- `파일공유.exe` : 실행 파일 (설치 필요 없음)
- 이 저장소 : 소스 코드 (Go). `build.bat`으로 exe 재생성

## 업데이트
- 프로그램 오른쪽 위 **업데이트 확인** (또는 트레이 메뉴)을 누르면 새 버전을 받아 바로 적용하고 다시 켜집니다.
- 프로그램을 켤 때(켜 둔 동안에는 12시간마다) 새 버전이 있는지 확인해서, 있으면 알림과 아래 상태줄로 알려 줍니다. 인터넷이 안 되면 아무것도 표시하지 않습니다.
- 새 버전은 이 저장소의 `release/` 폴더에 올립니다.
  1. `appVersion`(main.go)을 올리고 `build.bat`으로 exe 빌드
  2. exe를 `release/fileshare.exe`로 복사
  3. `release/version.json`의 `version`과 `sha256`(exe의 SHA-256)을 새 값으로 바꿔서 커밋
